# Занятие вдвоём (pair)

Бесплатная доска для индивидуального занятия: учитель и ученик, общая доска, видео и звук.
Прод: https://pair.co-learn.ru

## Как устроено

Сервер только знакомит браузеры. Видео, звук и доска идут **напрямую** между участниками (WebRTC):

- `server/` — сигналинг на WebSocket (`/ws`), ~200 строк, одна зависимость (`ws`). Комната до 4 участников
  (двое людей + на будущее телефон-камера у каждого), лимиты на подключения с IP, частоту и размер сообщений,
  комнаты живут не больше 12 часов. Ничего не хранит.
- `client/` — Vite + TypeScript + fabric.js. Доска синхронизируется через RTCDataChannel операциями
  add / mod / del; при подключении стороны обмениваются снимками доски и объединяют их, поэтому
  перезагрузка страницы или опоздавший участник получают всё нарисованное.

**TURN-сервера нет намеренно.** Ретрансляция медиа стоит трафика, и через неё сервер можно нагрузить.
Если прямое соединение не установилось за 15 секунд, клиент честно пишет об этом и предлагает другую сеть.
STUN — публичный (Google), через него трафик не идёт.

## Разработка

```sh
cd server && npm ci && npm test && npm start     # 127.0.0.1:13119
cd client && npm ci && npm run dev               # 13121, /ws проксируется на 13119
```

Открыть http://localhost:13121, начать занятие, открыть ту же ссылку во второй вкладке.
В dev-сборке доска доступна в консоли как `window.board`.

Горячие клавиши: V выбор, H рука (или пробел), P ручка, M маркер, E ластик, L линия, A стрелка,
R прямоугольник, O эллипс, Y треугольник, T текст, I картинка; Ctrl+Z — отменить своё последнее;
Ctrl+колесо — масштаб; картинку можно вставить Ctrl+V или перетащить.

## Деплой

Push в `main` с изменениями в `pair/**` → `.github/workflows/deploy-pair.yml` (self-hosted runner на проде):
тесты сервера, сборка клиента в `~/co-learn/pair`, сервер в `~/co-learn/pair-server`, pm2 `co-learn-pair`.
nginx: `deploy/nginx/cooperative-pair.prod.conf`.
