# Занятие вдвоём (pair)

Бесплатная доска для индивидуального занятия: учитель и ученик, общая доска, видео и звук.
Прод: https://pair.co-learn.ru

## Как устроено

Сервер только знакомит браузеры. Видео, звук и доска идут **напрямую** между участниками (WebRTC):

- `server/` — сигналинг на WebSocket (`/ws`), ~200 строк, одна зависимость (`ws`). Комната до 4 участников
  (двое людей + на будущее телефон-камера у каждого), лимиты на подключения с IP, частоту и размер сообщений,
  комнаты живут не больше 12 часов. Ничего не хранит.
- `client/` — Vite + TypeScript + fabric.js. Доска синхронизируется через RTCDataChannel операциями
  add / mod / del; при подключении стороны обмениваются снимками доски и объединяют их, поэтому
  перезагрузка страницы или опоздавший участник получают всё нарисованное.

**Коды занятия.** У занятия два кода, сервер их не хранит:
- код учителя — 20 случайных знаков, ссылка `#t.<код>`; держать при себе;
- код ученика — 12 знаков, хеш кода учителя, ссылка `#<код>`; из него код учителя не получить.

Алфавит без похожих символов (нет 0/o, 1/l/i), показываются группами по 4 (`k7m2-x9pq-4hnt`), чтобы их можно было
продиктовать. При вводе принимаются любой регистр, дефисы и пробелы, кириллические двойники (а, е, к, р, с, у, х…)
и ссылка целиком; учитель это или ученик — понятно по длине. Ссылки собираются из кодов на лету.
`client/src/roles.ts` и `roomFromKey` в `server/server.mjs` должны совпадать. Сервер пускает учителем только того,
чей код хешируется в код комнаты, и сообщает всем, кто учитель.

На главной co-learn.ru (`landing/`) — плитка «Индивидуальное занятие», ведёт на pair.co-learn.ru.

**TURN-сервера нет намеренно.** Ретрансляция медиа стоит трафика, и через неё сервер можно нагрузить.
Если прямое соединение не установилось за 15 секунд, клиент честно пишет об этом и предлагает другую сеть.

**STUN свой** (`server/stun.mjs`, UDP 3478): браузер узнаёт свой внешний адрес, трафик занятия через него не идёт.
Внешние STUN не используем: Google из России недоступен, и любой зарубежный могут заблокировать.

## Настройки

Адреса в репозитории не хранятся. Сервер читает `server/.env` (образец — `server/.env.example`) и отдаёт
список STUN/TURN браузеру в ответе на вход в занятие (`joined.iceServers`). Без `ICE_SERVERS` браузеры
соединятся только внутри одной сети. Для встроенного STUN откройте в файрволе UDP-порт `STUN_PORT`.

## Разработка

```sh
cd server && cp .env.example .env               # и вписать свои адреса
npm ci && npm test && npm start                  # 127.0.0.1:13119 + STUN udp 3478
cd client && npm ci && npm run dev               # 13121, /ws проксируется на 13119
```

Открыть http://localhost:13121, начать занятие, ссылку ученика открыть во второй вкладке.
В dev-сборке в консоли доступны `window.board` и `window.peers`.

Инструменты слева; похожие собраны в группы, которые раскрываются вправо:
- выбор и закрепление (закреплённый объект нельзя выделить, сдвинуть или смести, пока не открепишь);
- перемещение доски; указка (красный след, который видит собеседник; на доске ничего не остаётся);
- ручка и маркер; ластик (стирает там, где провели) и метёлка (убирает задетый объект целиком);
- линии: прямая, вектор, отрезок, пунктир, двойная, волнистая, точка-тире, квадратная скобка, оси координат;
- разбор слова: приставка, корень, суффикс, окончание, основа;
- фигуры: прямоугольник, квадрат, ромб, эллипс, круг, треугольники, трапеция, шестиугольник, многоугольник по точкам;
- текст: шрифт, размер, жирный, курсив, подчёркивание. Шрифты свободные (SIL OFL) с кириллицей:
  Rubik, Montserrat, Comfortaa, PT Serif, JetBrains Mono, Bad Script (пропись), Caveat, Neucha, Marck Script,
  Lobster. Ставятся из npm-пакетов `@fontsource/*`, собираются в бандл и отдаются с нашего домена; файл шрифта
  грузится, только когда текст им набран;
- PDF: диалог с миниатюрами страниц, выбор щелчком или диапазоном («1-3, 5»), рамка обрезки на крупном
  виде страницы (одна на все выбранные). Страницы раскладываются по страницам доски вниз от первой
  пустой в столбце на экране, в заблокированный слой «Подложка». pdf.js грузится, только когда открывают PDF;
- картинка из файла и снимок со своей камеры. Снимок с камеры собеседника (например, его тетради) — кнопкой
  на его видео. Картинку можно обрезать рамкой и вернуть целиком (кнопки над выделенной картинкой).

Свои настройки (лист, цвет, толщина, заливка, текст) запоминаются в браузере (`localStorage`, ключ
`pair.prefs`) и подставляются в следующем занятии. Лист у участников общий; при встрече действует лист
учителя. Границы страниц по умолчанию оранжевые.

Слева внизу: закладки (запоминают, какая часть доски на экране и в каком масштабе; видны обоим)
и карта доски (всё нарисованное в уменьшенном виде; щелчок или перетаскивание по карте переводит туда).

Сверху: отмена и повтор своих действий, масштаб, «к началу доски», цвет (свой цвет, пипетка), толщина,
заливка фигур, меню доски (сохранить картинкой, сохранить в PDF, очистить), а также:
- **лист** (общий для обоих): разлиновка (клетка, линейка, пропись, каллиграфия, точки), цвет и толщина её линий,
  страницы: размер A5/A4/A3, книжная или альбомная, показывать ли границы (сплошные: красные, оранжевые,
  чёрные или коричневые; когда границы видны, размер клетки и строки чуть подгоняется под лист — примерно
  на 1%, — чтобы на странице было целое число клеток и строк, а разлиновка шла сплошной через границы).
  При видимых границах в углу каждого листа его координаты [столбец:строка], а рядом с масштабом —
  лист в центре экрана; нажатие на него открывает переход к листу.
  Доска делится на страницы
  от левого верхнего угла; в PDF сохраняется каждая страница, на которой что-то есть, своим листом
  выбранного размера (PDF собирается в браузере, без библиотек: `src/pdfwrite.ts`);
- **слои**, как в редакторе уроков: текущий слой (новое рисуется в нём), переименование двойным щелчком,
  порядок, блокировка, «скрыть у себя», у учителя ещё «скрыть от ученика» (у учителя такой слой бледный;
  данные всё равно уходят в браузер ученика, это для заготовок, не для секретов), перенос выделенного
  в слой, удаление слоя (объекты возвращаются по Ctrl+Z). Ластик стирает только в своём слое: слой со
  стёртыми местами рисуется на отдельном холсте и накладывается на нижние. У учителя ещё «Следовать за мной» (ученик видит ту же часть доски
в том же масштабе) и «Заблокировать доску ученика» (ученик только смотрит и показывает указкой).
Эти команды ученик принимает только от собеседника, которого сервер пометил учителем.
Над выделением появляется панель: дублировать, на передний и задний план, отразить, сгруппировать
и разгруппировать, закрепить, удалить.

Горячие клавиши: V выбор, K закрепление, H рука (или пробел), U указка, P ручка, M маркер, E ластик,
B метёлка, L линия, A вектор, R прямоугольник, O эллипс, Y треугольник, G многоугольник, T текст,
I картинка. Ctrl+Z / Ctrl+Shift+Z: отменить и повторить своё; Ctrl+C / Ctrl+V: копировать и вставить,
Ctrl+D: дублировать, Ctrl+A: выделить всё, Delete: удалить; Ctrl+колесо: масштаб. Картинку можно вставить
Ctrl+V или перетащить.

## Деплой

Push в `main` с изменениями в `pair/**` → `.github/workflows/deploy-pair.yml` (self-hosted runner на проде):
тесты сервера, сборка клиента в `~/co-learn/pair`, сервер в `~/co-learn/pair-server`, pm2 `co-learn-pair`.
`~/co-learn/pair-server/.env` деплой не трогает, он ведётся руками на сервере.
nginx: `deploy/nginx/cooperative-pair.prod.conf`.
