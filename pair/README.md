# Занятие вдвоём (pair)

Бесплатная доска для индивидуального занятия: учитель и ученик, общая доска, видео и звук.
Прод: https://pair.co-learn.ru

## Как устроено

Сервер только знакомит браузеры. Видео, звук и доска идут **напрямую** между участниками (WebRTC):

- `server/` — сигналинг на WebSocket (`/ws`), ~200 строк, одна зависимость (`ws`). Комната до 4 участников
  (двое людей + на будущее телефон-камера у каждого), лимиты на подключения с IP, частоту и размер сообщений,
  комнаты живут не больше 12 часов. Ничего не хранит.
- `client/` — Vite + TypeScript + fabric.js. Доска синхронизируется через RTCDataChannel операциями
  add / mod / del; при подключении стороны обмениваются снимками доски и объединяют их, поэтому
  перезагрузка страницы или опоздавший участник получают всё нарисованное.

**Коды занятия.** У занятия два кода, сервер их не хранит:
- код учителя — 20 случайных знаков, ссылка `#t.<код>`; держать при себе;
- код ученика — 12 знаков, хеш кода учителя, ссылка `#<код>`; из него код учителя не получить.

Алфавит без похожих символов (нет 0/o, 1/l/i), показываются группами по 4 (`k7m2-x9pq-4hnt`), чтобы их можно было
продиктовать. При вводе принимаются любой регистр, дефисы и пробелы, кириллические двойники (а, е, к, р, с, у, х…)
и ссылка целиком; учитель это или ученик — понятно по длине. Ссылки собираются из кодов на лету.
`client/src/roles.ts` и `roomFromKey` в `server/server.mjs` должны совпадать. Сервер пускает учителем только того,
чей код хешируется в код комнаты, и сообщает всем, кто учитель.

На главной co-learn.ru (`landing/`) — плитка «Индивидуальное занятие», ведёт на pair.co-learn.ru.

**TURN-сервера нет намеренно.** Ретрансляция медиа стоит трафика, и через неё сервер можно нагрузить.
Если прямое соединение не установилось за 15 секунд, клиент честно пишет об этом и предлагает другую сеть.

**STUN свой** (`server/stun.mjs`, UDP 3478): браузер узнаёт свой внешний адрес, трафик занятия через него не идёт.
Внешние STUN не используем: Google из России недоступен, и любой зарубежный могут заблокировать.

## Настройки

Адреса в репозитории не хранятся. Сервер читает `server/.env` (образец — `server/.env.example`) и отдаёт
список STUN/TURN браузеру в ответе на вход в занятие (`joined.iceServers`). Без `ICE_SERVERS` браузеры
соединятся только внутри одной сети. Для встроенного STUN откройте в файрволе UDP-порт `STUN_PORT`.

## Разработка

```sh
cd server && cp .env.example .env               # и вписать свои адреса
npm ci && npm test && npm start                  # 127.0.0.1:13119 + STUN udp 3478
cd client && npm ci && npm run dev               # 13121, /ws проксируется на 13119
```

Открыть http://localhost:13121, начать занятие, ссылку ученика открыть во второй вкладке.
В dev-сборке в консоли доступны `window.board` и `window.peers`.

Инструменты слева, похожие собраны в группы, которые раскрываются вправо: ручка/маркер, ластик/метёлка,
линия/стрелка, фигуры. Ластик стирает только там, где провели (штрих «прорезает» нарисованное до фона),
метёлка убирает задетый объект целиком.

Горячие клавиши: V выбор, H рука (или пробел), P ручка, M маркер, E ластик, B метёлка, L линия, A стрелка,
R прямоугольник, O эллипс, Y треугольник, T текст, I картинка; Ctrl+Z — отменить своё последнее;
Ctrl+колесо — масштаб; картинку можно вставить Ctrl+V или перетащить.

## Деплой

Push в `main` с изменениями в `pair/**` → `.github/workflows/deploy-pair.yml` (self-hosted runner на проде):
тесты сервера, сборка клиента в `~/co-learn/pair`, сервер в `~/co-learn/pair-server`, pm2 `co-learn-pair`.
`~/co-learn/pair-server/.env` деплой не трогает, он ведётся руками на сервере.
nginx: `deploy/nginx/cooperative-pair.prod.conf`.
